# 积木攻城（原型）

3D 回合制搭建对战游戏的第一个可玩原型。双方用同一批随机材料搭堡垒、造武器，轮流开炮，先打碎对方核心的一方获胜。现在的对手是电脑，联网对战放在下一步。

## 怎么玩

1. **搭建（2 分钟）**：点格子往上叠方块。木、石、铁三种方块血量不同（木 40 / 石 85 / 铁 170）。
   - 核心必须放，只有一个。
   - 投石机：4 木 + 1 石，高抛弹道，能越过城墙砸屋顶，每发消耗 1 块石头。
   - 加农炮：3 铁 + 1 木，平射弹道，冲击力大，每发消耗 1 块铁。
   - **没用完的石头和铁就是炮弹**，所以每多建一块，就少打一炮。
   - 不想自己搭可以点"自动搭一个"，电脑会用你的材料先搭一座，你再改。
2. **揭晓**：时间到或点"完成搭建"后，对方的堡垒从天而降。
3. **对战**：轮流开炮。调方向、仰角、力度，白点是弹道开头，红圈是你上一发的落点。
   - 爆炸会伤害范围内的方块；挡在核心前面的方块能挡掉一半以上的伤害。
   - 方块被打碎、被炸飞、从高处摔下都会掉血；掉进海里直接消失。
   - 武器被打碎或被打翻就不能再用。
4. **胜负**：核心血量归零或掉下岛就输。40 发打完或双方都打不了时，比核心剩余血量。

电脑上：拖动鼠标转视角，滚轮缩放；瞄准时 A/D 方向、W/S 仰角、Q/E 力度（按住 Shift 微调），空格开火。

## 运行

```bash
npm install
npm run dev        # 本地开发，浏览器打开终端里显示的地址
npm run build      # 类型检查 + 打包成单个 HTML（dist/index.html）
npm run smoke      # 无头浏览器自动玩几回合，截图存到 test-output/
```

`npm run build` 还会生成 `dist/artifact.html`，内容和 `dist/index.html` 一样，只是去掉了外层的 `<html>`/`<head>`/`<body>` 标签，用来发布成可分享的网页。

## 技术栈

- **Three.js**：3D 渲染、阴影、泛光后期
- **cannon-es**：刚体物理（纯 JS，不依赖 WebAssembly，以后可以原样搬到 Node 服务器上跑）
- **TypeScript + Vite**：打包成一个自带全部代码的 HTML 文件
- 美术和音效全部由代码生成：方块贴图用 Canvas 绘制，音效用 Web Audio 实时合成，没有外部素材

## 代码结构

| 文件 | 内容 |
|---|---|
| `src/config.ts` | 数值：材料血量和重量、武器造价和弹道、随机材料池 |
| `src/fort.ts` | 堡垒数据模型（7×7 格，每格一摞），放置规则，格子和世界坐标换算 |
| `src/arena.ts` | 对战：物理世界、开炮、爆炸、伤害、倒塌、落水 |
| `src/ai.ts` | 电脑：搭堡垒的套路、计算弹道（越打越准） |
| `src/ballistics.ts` | 弹道公式、轨迹预览 |
| `src/main.ts` | 游戏流程（搭建 → 揭晓 → 回合 → 结算）、输入、镜头调度 |
| `src/fx.ts` | 粒子、碎块、冲击波、闪光 |
| `src/camera.ts` | 镜头：自由环绕 / 导演模式、屏幕震动 |
| `src/world.ts` | 天空、海面、浮岛、云、旗子、敌方迷雾罩 |
| `src/pieces.ts` / `src/textures.ts` | 方块、核心、武器的模型和程序化贴图 |
| `src/audio.ts` | 程序化音效 |
| `src/ui.ts` + `index.html` | 界面 |

## 下一步：联网

回合制让联网简单很多，计划是：

1. 服务器用 Node.js + Colyseus 管房间和匹配。
2. 搭建阶段双方各自在本地搭，完成后只上传"每格放了什么"的清单，服务器校验材料是否超用。
3. 对战阶段客户端只上传瞄准参数（方向、仰角、力度），**物理由服务器算**，算完把方块轨迹录像发给双方播放。这样两边画面一定一致，也没法作弊。cannon-es 是纯 JS，`src/arena.ts` 基本可以直接搬到服务器。
